libheif and libde265
=====================

A Windows build of Cerno with the heic feature loads these two libraries
at run time as separate DLLs. Both are licensed under the GNU Lesser
General Public License, version 3. The GPL-3.0 and LGPL-3.0 texts are
in this folder (LGPL-3.0.txt, GPL-3.0.txt).

You may replace heif.dll and libde265.dll with other builds that keep a
compatible interface. Cerno then uses the versions you supply.

    Component    Version    License
    libheif      1.23.1     LGPL-3.0-only
    libde265     1.1.1      LGPL-3.0-only

Corresponding source of these versions:

    https://github.com/strukturag/libheif/archive/refs/tags/v1.23.1.tar.gz
    https://github.com/strukturag/libde265/archive/refs/tags/v1.1.1.tar.gz

Built with vcpkg revision c76c06644034521fb761a39f8f52d8e87d1103d5
(tag 2026.07.29), port feature libheif[core]. That feature set does not
include the x265 encoder (GPL).

On Linux, Cerno links the system's libheif. A Linux package should depend
on the distribution's libheif and libde265 packages rather than bundling
static copies.
