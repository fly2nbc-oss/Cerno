libheif and libde265
=====================

A Windows build of Cerno with the heic feature loads these two libraries
at run time as separate DLLs. Both are licensed under the GNU Lesser
General Public License, version 3. The GPL-3.0 and LGPL-3.0 texts are
in this folder (LGPL-3.0.txt, GPL-3.0.txt).

You may replace heif.dll and libde265.dll with other builds that keep a
compatible interface. Cerno then uses the versions you supply.

    Component    Version    License
    libheif      1.23.5     LGPL-3.0-only
    libde265     1.1.3      LGPL-3.0-only

Corresponding source of these versions:

    https://github.com/strukturag/libheif/archive/refs/tags/v1.23.5.tar.gz
    https://github.com/strukturag/libde265/archive/refs/tags/v1.1.3.tar.gz

Built with vcpkg revision b30c88338f4ec47a322a81f4113d7385702e03a7
(master of 2026-09-22), port feature libheif[core]. That feature set does not
include the x265 encoder (GPL).

On Linux, Cerno links the system's libheif. The .deb package depends on
the distribution's libheif and libde265 packages. The AppImage bundles
the shared libraries of Ubuntu 24.04 (libheif1, libheif-plugin-libde265,
libde265-0) in usr/lib; usr/share/doc/cerno/bundled-libraries.txt names
their versions. Corresponding source: Ubuntu's source packages,

    https://launchpad.net/ubuntu/+source/libheif
    https://launchpad.net/ubuntu/+source/libde265

You may replace those files inside an extracted AppImage
(--appimage-extract) with interface-compatible builds.
